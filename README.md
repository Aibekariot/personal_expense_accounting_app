# Мои финансы

Учёт личных доходов и расходов. Написано на Flutter и собирается как веб-приложение (PWA),
которое ставится на iPhone и Android через «На экран Домой». Данные хранятся локально
на устройстве (SQLite в браузере), на сервер ничего не отправляется.

## Возможности

- **Операции**: расходы, доходы, переводы между счетами и обмен валют (две суммы,
  курс обмена считается сам), корректировка баланса. Изменение, удаление, «повторить».
- **История** по дням с итогами, поиск (по категории, комментарию, сумме), фильтры
  по виду операции, счёту и категории.
- **Счета** в разных валютах, общий капитал в основной валюте, архив счетов.
- **Валюты**: свои валюты, курсы из интернета (раз в 6 часов) и ручные курсы, конвертер.
- **Статистика**: доли категорий (с подкатегориями), сравнение с прошлым периодом,
  доходы/расходы по месяцам, капитал по месяцам, крупнейшие расходы, прогноз на месяц.
  Суммы в других валютах пересчитываются по курсу на дату операции.
- **Бюджеты**: месячные лимиты по категориям, прогноз, «можно тратить в день»,
  предупреждение при вводе расхода.
- **Долги**: кому дал и у кого взял, частичные возвраты (в том числе в другой валюте),
  сроки и просрочка.
- **Резервная копия** в файл и восстановление, выгрузка операций в Excel (CSV),
  напоминание о копии.

## Команды

| Что сделать | Команда |
|---|---|
| Установить зависимости | `flutter pub get` |
| Запустить в браузере | `flutter run -d chrome` |
| Перегенерировать код базы (после изменения `tables.dart`) | `dart run build_runner build` |
| Тесты | `flutter test` |
| Собрать веб-версию | `flutter build web --release` → папка `build/web` |
| Перерисовать иконки | `flutter test tool/generate_icons_test.dart` |

## Публикация (GitHub Pages)

Файл `.github/workflows/deploy.yml` при каждом push в `main` прогоняет тесты, собирает
веб-версию и публикует её на `https://<пользователь>.github.io/<репозиторий>/`.
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

Адреса внутри приложения — с `#` (`…/#/operations`), поэтому обновление страницы
на GitHub Pages работает без настройки сервера.

## Правила проекта

- **Деньги — только целые числа** в минимальных единицах валюты (тыйыны, центы):
  `1 500,50 сом = 150050`. Форматирование, разбор и пересчёт — в `lib/core/money.dart`.
- **Баланс счёта и остаток долга не хранятся**, а вычисляются из операций. Поэтому
  после правки или удаления операции всё пересчитывается само и расхождений нет.
- **Переводы, корректировки и долги** — не расходы и не доходы, в статистику не попадают.
- **Изменение таблиц** — только с миграцией: увеличить `schemaVersion` в
  `app_database.dart`, добавить шаг в `onUpgrade` и поддержать старые копии
  в `BackupService.parse`.
- **Файлы `web/sqlite3.wasm` и `web/drift_worker.js`** должны совпадать по версиям
  с пакетами `sqlite3` и `drift` из `pubspec.lock`. При обновлении этих пакетов
  скачайте файлы заново:
  - `https://github.com/simolus3/sqlite3.dart/releases/download/sqlite3-<версия>/sqlite3.wasm`
  - `https://github.com/simolus3/drift/releases/download/drift-<версия>/drift_worker.js`

## Структура

```
lib/
  app/          приложение, навигация, тема
  core/         деньги, форматирование, общие виджеты, работа с файлами браузера
  data/db/      таблицы, база данных, начальные данные, миграции
  data/         репозитории, курсы валют, резервная копия, провайдеры
  domain/       расчёты: история, фильтры, статистика, бюджеты, долги, периоды
  features/     экраны: операции, счета, статистика, категории, бюджеты,
                долги, валюты, резервная копия
test/           тесты расчётов и базы данных
tool/           генератор иконок
```
